# 마음편

30대 초반~40대 초반 여성을 중심으로 기획한, 작고 가벼운 운세·해석 서비스의 첫 인터랙티브 시안.

## 실행

Node.js 20 이상에서 `node server.mjs` 실행 후 http://127.0.0.1:4173 접속. 별도 설치나 빌드가 필요하지 않습니다. 배포 파일은 `dist/`입니다.

## 현재 구현

- 모바일 전용 홈과 자체 SVG 행운 기계·일러스트. PC에서도 최대 480px 단일 화면과 하단 탭을 사용합니다.
- 현재 마음 4종에 따른 뽑기 애니메이션 및 고정 예시 카드
- 브라우저 로컬 서랍 저장, 삭제, 재방문 유지
- Web Share 지원 또는 클립보드 문장 복사
- 두 별명과 관계 단계에 따른 궁합 대화 가이드 3종
- 3,900원 가격 가안 및 실제 청구 없는 전체 해석 체험
- 기다리는 마음을 위한 무료 편지 4종
- 일과 선택을 위한 짧은 읽을거리

## 범위

실제 사주 계산, AI 개인화, 사용자 인증, 결제, 서버 데이터베이스는 연결하지 않았습니다. 입력을 근거로 미래·의학적 결과를 예측하지 않습니다. 별명과 저장한 콘텐츠만 localStorage에 보관합니다. 궁합 입력은 메모리에서만 사용합니다. 웹폰트는 Google Fonts에서 불러오며 실패하면 로컬 대체 폰트를 사용합니다.

## 디자인

Playful / Toy-like 방향. 크림 바탕, 짙은 초록, 보조 분홍색. 고운바탕 헤드라인과 Noto Sans KR 본문, 8px 기반 간격. 기억할 요소는 자체 제작 클로버 뽑기 기계입니다. DFII: 영향 4 + 적합 5 + 구현 5 + 성능 5 - 일관성 위험 4 = 15. 움직임은 뽑기와 짧은 화면 전환에 한정하고 reduced-motion을 지원합니다.
